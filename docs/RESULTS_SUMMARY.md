# Results Summary

## Validation Setup

The KenPom model uses seasons 2002 through 2024, with 2020 absent because there was no NCAA tournament.

| Split | Seasons |
| --- | --- |
| Rolling validation | 2008 through 2017 |
| Final train window | 2002 through 2017 |
| Locked final test | 2018, 2019, 2021, 2022, 2023, 2024 |

The locked final test contains 401 tournament games.

## GBT Model Search

The best rolling-validation GBT settings were identical for `kp_only` and `kp_seed`:

| Model | Rolling Mean Logloss | Best Param Set |
| --- | ---: | ---: |
| `kp_only` | 0.6275 | 4 |
| `kp_seed` | 0.6313 | 4 |

Best parameters:

```text
learning_rate=0.03
max_iter=300
max_depth=3
min_samples_leaf=50
l2_regularization=1.0
```

## Baseline Comparison

Final test results from `reports/baseline_scores_kenpom.csv`:

| Feature Set | Model | Logloss | Accuracy |
| --- | --- | ---: | ---: |
| `kp_only` | logistic L1 | 0.5839 | 0.6908 |
| `kp_only` | logistic L2 | 0.5863 | 0.6883 |
| `kp_seed` | logistic L1 | 0.5873 | 0.6933 |
| `kp_seed` | logistic L2 | 0.5903 | 0.7007 |

The strongest logistic baseline beats the GBT on logloss. That is a meaningful result: for this dataset size, a simple linear model over high-signal KenPom differences is hard to beat.

## Feature Importance

Top KenPom permutation-importance results show the model depends most on overall adjusted efficiency:

| Rank | Feature | Mean Delta Logloss |
| ---: | --- | ---: |
| 1 | `kp_adj_em_diff` | 0.0752 |
| 2 | `kp_adj_oe_diff` | 0.0236 |
| 3 | `kp_adj_de_diff` | 0.0150 |
| 4 | `abs_kp_adj_em_diff` | 0.0125 |
| 5 | `kp_to_pct_diff` | 0.0108 |

Interpretation: overall team quality drives the model, followed by offensive and defensive efficiency. Style statistics help at the margin.

## Current Prediction Output

`reports/game_by_game_results_kenpom.csv` contains deterministic bracket picks generated by advancing the predicted favorite each round. The file includes:

- round
- region
- winning and losing seed
- winning and losing team ID
- winning and losing team name
- predicted win probability

This output is easy to present, but it is not a full simulation of bracket uncertainty. A next improvement would be Monte Carlo bracket simulation using the same pairwise probabilities.

## Takeaways

- KenPom adjusted efficiency margin is the central signal.
- Raw GBT probabilities outperform sigmoid and isotonic calibration in the current locked test.
- Logistic baselines remain very competitive and should be included in any final presentation.
- Seeds add accuracy in some comparisons but do not consistently improve logloss.
- A polished next step would be an ensemble or blended probability model using logistic and GBT predictions.
